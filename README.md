Welcome to the Ancestry tracks project. 

Getting Started:

Follow the steps below to run the project locally using Visual Studio Code. VSCode is free to use.

1. Download or clone the repo.
2. If downloaded open the project into VSCode.
3. Open up a terminal and run "npm run dev"
4. Open up terminal two and navigate to the front end "cd frontend/". In this terminal now in the front end run "npm run dev"
5. You should now see a local host "http://localhost:5173/" Click this. It will send you to a browser with the Acnestry Tracks project up.
